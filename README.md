<b>🐈 MeowTg - A typescript user-bot software for telegram with dynamic plugins system.</b>

### 😌 Features
* 📦 Plugins system
* 💾 Plugins management (by .pkg command)
* 🌎 Online plugins repositories
* 📋 Configuration wizard
* 🧹 Zero default behavior
